# PUF CP：结构定位、CCR 与预测模型扩展分析

## 主要结论

1. **可重复的分类信号仍以蛋白内部高概率非局部接触密度为主。** CP summary 的 Random Forest、XGBoost 在14种构建的LOCO中AUC均为1.000；固定0.5阈值下均13/14正确，3个成功构建中识别2个。
2. **新增CCR、残基密度、pLDDT、PAE与紧凑度没有一致提升。** 全特征LR/RF AUC均为0.818，XGBoost为1.000；仅12-repeat子集上全特征XGBoost为0.963，低于summary XGBoost的1.000。不能将AUC提高归功于CCR。
3. **局部候选以P5–P6界面为优先关注区域。** K204、A235及K204–E239、L196–A235具有较强探索性关联；P7–P8也有接触减弱候选。这里P表示N端到C端的repeat顺序，区别于来源repeat R。
4. **尚无通过BH多重检验校正的单条接触或单个残基。** 结果支持生成可检验的结构假设，尚不能证明这些接触决定构建成功。

## 数据与编号规则

使用上一轮两个原始folds ZIP及PUF_CP_analysis.zip：14种构建，成功3种、失败11种；56个seed任务、280个模型。每seed先平均5个模型，再对seed等权平均；14种构建作为独立标签。所有文件均纳入，未筛选最高ranking或最高pLDDT模型。3种成功标签沿用用户指定名单。

参考编号固定为 **PUF12 R123 R567 R567 R678 的A链原始1-based残基号**，包括N端标签；以下K204等都使用该编号。用户此前其他蛋白序列可能使用不同起点，不能直接照搬。

基于TRM锚点对齐：在输入序列中识别MNDGPHS loop片段并保留其原始位置映射，移出36-aa核心对齐；剩余序列中的12/13/16位TRM锚点呈36-aa周期。每个repeat核心单独按位置对齐，P1–P12为构建中N→C的槽位。来源R1–R8通过参考模块序列、排除TRM位点后最近匹配推断；来源标签为序列推断，身份相似度随表附上。

PUF11的P12按缺失值处理。主接触检验仅使用14种构建都存在的P1–P11；另对12种PUF12使用完整P1–P12进行敏感性分析。该对齐比较对应的架构槽位，不把不同来源的repeat称为相同天然同源残基。插入loop缺乏一一对应的位置，未把缺失loop当作零CP；loop本体不参与逐对检验，完整蛋白的汇总指标与残基接触密度仍包含它们的接触贡献。

参考构建来源顺序为R1,R2,R3,R5,R6,R7,R5,R6,R7,R6,R7,R8。因此本文P5–P6界面对应来源R6–R7界面。

## 1. ΔCP与接触统计

直接读取AlphaFold输出`contact_probs`。ΔCP定义为成功构建均值减失败构建均值。只计上三角中核心序列间隔≥12的位置；使用标签无关筛选：所有受检构建该位置可用、最大构建均值CP≥0.1、非零变异。

- 14构建主检验：689条接触，BH q<0.05为0条，最小q=0.3487。
- 12-repeat敏感性检验：801条接触，BH q<0.05为0条，最小q=0.5985。
- Pearson r：各构建CP与二元成功标签的相关系数（point-biserial相关）。
- Effect size：成功−失败的原始ΔCP与小样本修正Hedges g；同时输出原始均值，避免较小绝对差异被标准化放大。

## 2. Top CCR

本分析的CCR是操作性定义：同一repeat内连续3–12个核心残基，其非局部接触密度在构建间协同变化。每加入一个残基，要求与组内所有已有残基的Pearson r≥0.6；再保留区域平均密度与标签|r|≥0.4的区域，按|r|排序。该规则下仅得到两个候选，不人为扩充区域。

残基密度D_i为该残基与完整蛋白中序列间隔≥12残基的CP之和；区域特征为区域内D_i均值。

- **CCR01：H178、T179、E180，P5位置1/2/3，来源R6。** 区域内平均残基相关0.733；标签r=0.599，Hedges g=1.581。参考结构中H178、E180有非局部跨repeat高CP接触，T179未满足同一阈值。H178的高CP跨repeat伙伴位于P4，E180的伙伴位于P6；详细伙伴编号见CCR_interface_partners.csv。三者都不属于TRM 12/13/16，也不满足本分析的RNA高CP接触标准，距MNDGPHS片段均超过5 aa。

## 4. LOCO模型比较

每次完整留出一种构建；训练折内重新发现CCR并选择8个标签相关度最高的残基。缺失值中位数填充、标准化、树模型训练均仅在训练折拟合。最多取5个CCR，每个CCR加入密度、pLDDT、CP加权PAE三个特征。主全数据最终选到2个CCR，因此最终全特征模型为45维；不同训练折的CCR数量可变。

特征组：

- summary：上一轮14个CP汇总特征。
- structural：summary加17个结构指标，共31维，含pLDDT分布、PAE、Cα回转半径、长度归一化回转半径、核心最大Cα距离、形状各向异性、残基密度汇总。
- full：structural加训练折内的8个残基密度与CCR特征。

参数固定，未用外层LOCO选参数或阈值：LR C=0.1、类别平衡；RF 300棵树、深度2、叶节点最少2；XGBoost 100轮、深度1、学习率0.05、L2=10、L1=1、列采样0.8、按训练集类比例加权。无外层早停，阈值固定0.5。

## 5. 可用于新设计的冻结评分

### A. 推荐保留的CP summary XGBoost分数

最终在14种构建上重新训练的100棵深度1树，仅使用三个高CP接触密度：

S_d = 完整蛋白中满足 i<j、j−i≥d、CP_ij>0.5 的接触对数 / 蛋白残基数L，d取4、12、24。

先对模型、再对seed求均值。最终模型可近似写成：

h_d = +1（S_d≥t_d），否则−1。

**z ≈ 0.80797146 h_4 + 0.26164738 h_12 + 0.05974436 h_24**

**score = 1 / (1 + exp(−z))**

参考阈值：t4≈2.379752851；t12≈1.316894531；t24≈1.120605469。

这些是全数据重训的冻结模型阈值，LOCO评估每折重新训练。公式中阈值经过小数展示，数值边界以保存的模型为准；`XGBoost_scoring_formula.json`保留标准化阈值及浮点比较规则。与保存模型核对的最大分数误差<10^-6。该模型在训练集上只有两类分数约0.244/0.756，**训练集分数不用于报告泛化性能**。

这三个指标都衡量全局接触密度，彼此相关。d=4还包含较局部的折叠接触，模型结果不能证明所有预测信号都来自repeat间界面。

### B. 可解释的四项连续结构评分

若希望同时观察置信度与紧凑度，另提供固定LR：

**z = 3.79940090 + 8.61723356 S12 + 0.12351811 P − 0.48797589 A − 5.80094544 R**

score = sigmoid(z)。

P：每个蛋白残基先对原子pLDDT平均，再对残基平均。
A：蛋白内部非局部接触的CP加权对称PAE，单位Å；只计i<j且j−i≥12。
R：Cα回转半径Rg除以L^(1/3)，按保存代码单位计算。

四项分数LOCO AUC=0.909、固定阈值0.5时11/14正确，未超越summary XGBoost。它用于解释与排序，不作为更强模型宣传。

两种分数均未概率校准，不是实验成功概率；未见骨架、超出训练分布的设计、不同RNA长度/序列与不同预测设置都需要重新验证。当前所有训练RNA均为13nt AUGGAGGACGUGC。

### 使用方式

解压后在包根目录运行：

```bash
python extended/score_new.py --zip new_folds.zip --out scores.csv
python extended/score_new.py --zip new_folds.zip --model formula4_LR --out continuous_scores.csv
```

ZIP输入采用本批AlphaFold-server布局，目录为`*_rna_*_seedN`，内含full_data JSON与对应model CIF，A链蛋白、B链RNA。支持传入多个ZIP，但请避免重复提供同一预测任务。需要完整、多seed的模型集合；脚本会先按seed内模型平均，再按seed平均。也可用`--features features.csv`输入与导出表一致的特征列。

已用原始ZIP中的参考构建完成端到端核对，连续分数与特征CSV评分误差约2.9×10^-7；XGBoost公式也与保存模型核对通过。`structural4_any_abs_z_gt3`仅检查四个连续结构变量，不是完整分布外检测。

## 建议如何使用结论

以全局接触密度作为新设计的初筛参考；将K204–E239、L196–A235与P5–P6界面作为待解释的局部信号。CCR01/02和高RF重要性残基尚未体现稳定新增预测价值，不据此直接断言应增强/减弱某个残基的作用。明确“成功”对应克隆、表达还是功能环节后，再用独立新构建验证。若标签对应克隆/测序成功，CP本身无法定位DNA重复重组或引物失败原因。

## 复现与方法来源

把两个原始folds ZIP放入`inputs/`，包内已附上一轮必要的序列与汇总表。按顺序运行extract.py、discover.py、models.py、sensitivity.py、plot_results.py；score_new.py可独立用于冻结模型。所有模型与绘图随机种子固定，版本见provenance.json。CRC/结构映射与评分一致性检查见validation_checks.json。

PUF repeat通常约36 aa，TRM为repeat内12/13/16位；本研究锚点编号参考下述原始研究，但CCR算法与成功标签分析为本批数据的探索流程：

Zhou, W., Melamed, D., Banyai, G., Meyer, C., Tuschl, T., Wickens, M., Cao, J., & Fields, S. (2021). Expanding the binding specificity for RNA recognition by a PUF domain. *Nature Communications, 12*, 5107. https://doi.org/10.1038/s41467-021-25433-6
