# Figure source data

The current Wiki uses `fixed4_test_predictions.csv`, `training20_s12.csv`, `fixed5_endpoint_predictions.csv` and `fig5_model3_nontrm_consensus.csv`. These support the fixed-four test, training-only scaffold feature distribution, fixed-five endpoint test and unchanged non-TRM sampling-support figure.

[Fixed-test protocol](../../research/fixed_test_20260923/README.md) · [Plotting script](../scripts/make_fixed_test_figures.py). Other tables in this directory are historical figure sources and do not define the current test metrics.

`model2_repeat_importance_percent.csv` contains the frozen Model 2 contact-importance shares for all twelve repeats and the outside-core region. The [interpretation source tables](../../research/model_interpretation_20260923/) preserve residue-level weights, numbering crosswalks, MPNN frequencies and all 81 exact mutation-to-assay comparisons.
