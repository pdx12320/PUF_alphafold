# PUF–APOBEC Dry Lab：Design–Build–Test–Learn

更新：2026-09-23。当前 Wiki 按“背景—模型解释—训练或采样效果—实验比较—下一轮设计”组织三个模型，完整正文见 [English](wiki/PUF_Model_EN.md) / [中文](wiki/PUF_Model_ZH.md)。本页先概述当前工程闭环，再保留 2026-09-20 的开发记录。

## 当前工程目标

PUF repeat 排列决定可用骨架的范围，TRM 改动影响 RNA 识别，识别位点之外的残基为下一轮设计提供补充方向。三个模型分别对应骨架功能、三位点编辑表型和非 TRM 突变提名。实验终点始终分开记录：Model 1 使用实验记录中的 work/non-work 标签；Model 2 使用 C388、C295、C871 的实测编辑率；Model 3 交付待检验的序列。

## Model 1：建立骨架规则，再与四个构建的实验标签比较

**背景与 Design。** 扩展 PUF repeat 数目和调整排列可能改变蛋白接触模式。我们首先检验能否用低维结构特征预测实验记录中的 work/non-work 标签，为湿实验减少候选范围。

**Build 与训练效果。** 初始浅层决策树以非局部蛋白接触密度建立可解释基线，构建留一分析中 14/14 判断正确。后续使用浅层随机森林整合接触密度、pLDDT、PAE 和几何特征。当前复现采用 300 棵最大深度为 2 的树，预测阈值固定为 0.5；特征及参数见[冻结方案](../results_20260922/scaffold_RF/audit/protocol.json)。在较完整的构建留一评估中，CP＋结构模型判断正确 22/24。

**Test：一个 work、三个 non-work。** 四构建比较将四个成员同时排除，用其余 20 个构建拟合随机森林，然后与四个构建已有的湿实验标签比较。模型正确预测唯一记录为 work 的构建，并正确判定两个记录为 non-work 的构建；另一个 non-work 被判为 work，因此共 3/4 一致（TP=1、TN=2、FP=1、FN=0）。这个结果对应当前随机森林；初始决策树的内部验证单独呈现。该比较为已有实验记录上的回顾性留出评估。

**Learn → 下一轮 Design。** 接触与结构特征能够形成筛选依据，四构建比较同时保留一次误报，便于后续检验不同 repeat 排列上的判别能力。下一轮可将模型判为 work 的新排列交给湿实验，并按同一标准记录所有结果。

展示入口：[四构建混淆矩阵](wiki/figures/fig1_model1_four_construct_confusion.svg)、[构建留一混淆矩阵](wiki/figures/fig2_model1_loco_confusion.svg)、[完整指标](../results_20260922/scaffold_RF/results/metrics.csv)。

## Model 2：预测 TRM 编辑表型，再比较五个候选的三位点实验结果

**背景与 Design。** 可用骨架上的 TRM 变化需要同时考虑 C388 活性和 C295/C871 旁观者编辑。各位点以匹配对照为参考，将编辑率变化表示为百分点，并建立相应的类别预测任务。

**Build 与训练效果。** 模型从变体相对对照的蛋白–RNA 接触变化中提取局部、远端、全局或参考界面特征。训练流程选择位点对应的分类器和编辑率阈值，随后输出留出构建的编辑类别。不同折可使用不同分类器与阈值，具体设置保存在[逐项结果表](../results_20260922/five_construct_holdout/predictions.csv)。

**Test：五个实验表现良好的 TRM 构建。** 展示 P8-GVE、P9-GNS、P9-NPS、P9-NTQ 和 P4-R5-SNE+P7-R5-SNE。每个构建在自身预测折中从训练集排除，比较其预测与实测的三个编辑终点；五个构建按已有实验表现选取，用于回顾性展示。五者实测 C388 编辑为 60.46%–80.34%，C871 相对匹配对照降低 30.70–57.27 个百分点。双 P4/P7 构建还同时提高 C388 编辑并降低 C295/C871 编辑。

15 项位点判断有 13 项一致：C295 为 5/5，C388 为 4/5，C871 为 4/5。两项差异分别是 P9-GNS 的 C388 和 P8-GVE 的 C871。完整展示保留这两项，便于湿实验理解模型在哪些候选上低估了性能。[另一个十构建同时留出的排序分析](../results_20260922/ten_construct_holdout/ranking.csv)作为单独评估保留。

**Learn → 下一轮 Design。** P8、P9 以及 P4/P7 联合改动提供了可继续测试的识别 motif 背景。后续按固定条件比较三位点编辑，使模型预测与实验结论可以逐项对应，并进一步检验新的 TRM 组合。

展示入口：[三位点混淆矩阵](wiki/figures/fig3_model2_five_construct_confusion.svg)、[实测编辑率与匹配对照变化](wiki/figures/fig4_model2_measured_and_control_delta.svg)、[五构建原始结果表](../results_20260922/five_construct_holdout/predictions.csv)。

## Model 3：通过反向折叠提名非 TRM 突变，生成下一轮构建

**背景与 Design。** 在实验表现良好的识别 motif 基础上，进一步探索识别位点之外的结构可设计性。目标是形成可直接合成和比较的非 TRM 突变组合。

**Build 与采样流程。** 输入为 AF3 预测的 493 aa PUF12 与 17 nt RNA 复合物。预训练 ProteinMPNN 使用蛋白骨架；LigandMPNN 另引入 RNA 原子上下文。两个模型在温度 0.5 下各采样 10,000 条序列，计算每个位置的 WT 与替代氨基酸采样频率，再筛选替代残基并过滤识别位点。此流程使用预训练模型，项目实验记录用于后续比较和选择 TRM 背景。

**计算结果与实验衔接。** 当前结果包含 81 个非 TRM 位点提名，其中 17 个具体替换获得两个模型一致支持。已有 84 条实验变体记录用于解释模型输出与识别位点改造之间的关系，随后将稀疏非 TRM 替换叠加到实验表征过的 TRM 背景，生成 G0–G10 共 11 条构建序列。

| 设计分组 | 提名突变 | 下一轮实验要回答的问题 |
|---|---|---|
| N 端候选 | R45T；N12S、S30A、L41R | 在保留既有 TRM 的条件下，这些改变如何影响三位点编辑？ |
| 六残基组合 | T350V、D374E、M458L、L274I、T278I、V366I | 结构兼容性信号能否带来可测量的功能收益？ |
| 界面邻近候选 | A438G、H392D | 这组改变对目标与旁观者编辑有何影响？ |
| 组合及背景比较 | G0–G10，包含 P8-GVE、P9-NTQ、P7-SYVIRR 背景 | 单组或组合突变的效果是否依赖 TRM 背景？ |

**Learn → 下一轮 Design。** G0 提供 P8-GVE 基准，其余构建检验单组突变、组合突变和背景差异。所有非 TRM 设计均为计算候选，其结构作用和编辑收益需要实验检验。当前流程已交付带明确编号和序列的实验设计，见 [G0–G10 CSV](../aice_mpnn_20260922/results/gen3_constructs.csv) / [FASTA](../aice_mpnn_20260922/results/gen3_constructs.fasta)。

展示入口：[17 个双模型共识突变](wiki/figures/fig5_model3_nontrm_consensus.svg)、[完整采样与设计流程](../aice_mpnn_20260922/README.md)。

### 工程目标与两条研究线

项目希望先筛选有功能潜力的 PUF repeat 排列，再在可用骨架上评估 TRM 改动能否保留 C388 编辑并降低 C295/C871 编辑。骨架构建成功标签和编辑率达标标签分别建模。前者是已有实验记录给出的 success/failure；后者由各位点实测编辑率定义，不能将低编辑直接归因于折叠失败。

| 研究线 | 设计变量 | 实验终点 | 当前保留入口 |
|---|---|---|---|
| 骨架 | repeat 来源、顺序和 loop 插入 | 构建 success/failure | [跨排列验证](../architecture_validation/PUF_architecture_validation_report.md) |
| TRM 与功能 | 同一骨架上的 TRM 变化 | C388 活性保留；C295/C871 编辑下降 | [22突变体C871/C295动态分类](../trm22_offtarget/REPORT.md)、[C388 优化](../c388_local_nonlocal_optimization/README.md) |

统一的实验单位是 construct。AF3 的多个 model 先在 seed 内汇总，再对 seed 等权汇总。同一蛋白的不同 RNA 背景、seed 和 model 不增加独立蛋白数。下文 BA 为两类召回率的平均值，pp 为百分点；AUC 描述排序，固定阈值分类结果需结合 TP/FP/FN/TN 阅读。

### Cycle 1：用 CP 建立骨架筛选的初始基线

#### Design

提出可检验的问题：成功与失败构建是否在预测接触模式上存在可重复差异？优先比较蛋白内部接触与蛋白–RNA 接触，避免在极少构建上直接将完整 CP 矩阵作为高维输入。

#### Build

第一批包括 14 个构建，3 success / 11 failure，其中 2 个为 PUF11。共有 56 个 seed 任务、280 个结构 model；按 construct 聚合后用于训练。直接读取 AF3 `contact_probs`，提取 14 项 CP 汇总指标及 RNA 接触轮廓。

非局部高 CP 密度 S_k 的定义为：蛋白上三角中序列间隔至少 k、CP>0.5 的接触对数除以蛋白长度。k=4/12/24。该量允许大于 1；“非局部”只表示序列间隔条件，尚未定位到具体 repeat 界面。

#### Test

使用每次完整留出一个构建的 LOCO。初始 14 特征 Logistic 的 AUC=0.9091、BA=0.9091，TP=3、TN=9、FP=2、FN=0。浅层决策树在该批 14/14 正确，但属于小样本内部验证。RNA 接触轮廓 Logistic 的 AUC=0、BA=0.3182，未显示有效预测能力。构建均值层面，3 个成功构建的 S12 排在前三；seed 层面仍存在成功与失败重叠。

#### Learn → 下一轮设计

蛋白内部高 CP 密度值得作为简约基线。第一批的完美分类不能外推到新骨架；单个经验切点也不能作为通用阈值。下一轮增加结构置信度、几何量和 repeat 映射，检验局部结构能否解释并改善该信号。

**仓库处理：**初始分析报告、图表、专用脚本与结果目录 `previous/` 已退出当前快照；其历史证据保留在本节。后续骨架分析需要的序列输入已迁入 `data/architecture_inputs/`。

### Cycle 2：增加结构解释与 CCR，检验局部信息的价值

#### Design

检验 pLDDT、PAE、紧凑度、残基接触密度和连续协同变化区域（CCR）是否提供全局 CP 之外的信息。将候选定位到 repeat 槽位，区分位置 P 与来源 R。

#### Build

沿用第一批 14 个构建。以 36 aa repeat core 和 TRM 锚点建立映射；loop 缺失不填作零 CP。增加结构指标、逐残基和逐接触比较、CCR 发现、Logistic/RF/XGBoost 模型。使用构建级精确置换及 BH 多重检验校正。

#### Test

| 观察 | 当时结果 | 后续复核 |
|---|---|---|
| CP summary RF/XGBoost | LOCO AUC 均为 1.000；固定0.5均13/14正确，成功检出2/3 | 扩充构建与跨排列验证后成绩改变 |
| 全特征模型 | LR/RF AUC 均为0.818，XGBoost为1.000 | 增加特征没有一致收益 |
| 接触对探索 | 14构建检验689条接触，BH q<0.05为0条；12-repeat敏感性检验801条，同样0条 | 可生成结构假设，不能确立单条关键接触 |
| P5–P6局部候选 | L196–A235、K204–E239等显示探索性关联 | 编号依赖参考映射，缺乏校正后显著证据 |
| 原CCR01 | 在初始数据中形成候选 | 扩充后标签相关r≈−0.036、p≈0.915，协同性未复现 |

#### Learn → 下一轮设计

结构解释需要跨批次和跨排列复核。局部候选没有稳定替代低维 CP 汇总；旧 CCR01 的通用正向机制表述撤回。后续把两批 PUF12 合并，并按 repeat 排列整组留出，以检查模型是否主要依赖骨架背景。

**仓库处理：**`extended/` 的旧模型、图表、报告和分析脚本删除。后续分析所需的构建级矩阵、特征和映射逐字节迁入 `data/architecture_inputs/`；通用 `get_features` 函数迁入 `tools/cp_features.py`，未保留旧评分入口或旧权重。

### Cycle 3：扩充样本后检验 RF 调参是否值得继续

#### Design

两批合并得到 24 个 PUF12，4 success / 20 failure。检验提高模型复杂度或训练内选择阈值，能否超过固定浅层 RF。

#### Build

比较三密度、14项 CP summary、17项 CP＋结构特征。采用16组 RF 参数×3组特征；外层24折 LOCO，内层3折选择参数。另设置内层联合选择特征族与参数。分数阈值比较固定0.5和训练内 OOF 选择，不使用外层测试标签调阈值。

#### Test

| 特征/流程 | 原RF AUC | 调参后AUC | 原BA | 调参后固定0.5 BA | 调参后动态分数阈值BA |
|---|---:|---:|---:|---:|---:|
| 三密度 | 0.9125 | 0.9000 | 0.8250 | 0.8250 | 0.8250 |
| 14项CP summary | 0.8500 | 0.8750 | 0.7000 | 0.8250 | 0.8000 |
| 17项CP＋结构 | 0.9250 | 0.8125 | 0.7000 | 0.7000 | 0.6500 |
| 内层联合选择特征/参数 | — | 0.8625 | — | 0.7000 | 0.7000 |

三密度的调参没有改善分类计数，仍为 TP3/FN1/FP2/TN18。第二批 ID1 被识别，ID4/7 仍误报。14项特征调参有局部改善，但未全面超过简单基线。17项特征与联合选择显示不稳定。

#### Learn → 下一轮设计

停止把扩大调参搜索作为主路线。保留浅层基线，将验证重点转向 architecture-out。当前跨排列分析中，三密度 RF AUC=0.86875、BA=0.75；CP＋结构 RF AUC=0.9375，但固定阈值只检出2/4成功。该结果支持分开评估排序、召回和误报，不能用单一最高分决定模型成熟度。

**仓库处理：**`rf_tuning/` 的训练、评分脚本、权重、图表和表格删除；本节保留搜索设计、结果与停止继续调参的依据。`combined12/` 与 `architecture_validation/` 继续保留。

### Cycle 4：TRM 迁移检查暴露输入范围与样本独立性问题

#### Design

检查已成功骨架上的 TRM 变化能否沿用冻结骨架评分，并核对新输入与训练输入的一致性。

#### Build

91–96批共6个复合物，实际为2种蛋白（WT_PUF12-9、P8-R6-GVE）×3个RNA（C295/C388/C871），每个复合物1 seed、5 model。两种蛋白均519 aa；第8–519位对应512 aa分析范围，额外N端为SGSETPG。WT核心与训练中已知成功骨架完全相同。变体相对该WT有S304G/Y305V替换，未改变repeat排列。

#### Test

冻结三密度 RF 直接处理519 aa时，6个复合物都低于0.5。观察到误判后，排除额外7 aa并重算特征，未重新折叠、未重新训练模型：

| 蛋白 | RNA | 完整519 aa分数 | 512 aa核心分数 |
|---|---|---:|---:|
| P8-R6-GVE | C295 | 0.000 | 0.326 |
| P8-R6-GVE | C388 | 0.019 | 0.809 |
| P8-R6-GVE | C871 | 0.197 | 0.862 |
| WT_PUF12-9 | C295 | 0.051 | 0.862 |
| WT_PUF12-9 | C388 | 0.000 | 0.786 |
| WT_PUF12-9 | C871 | 0.000 | 0.786 |

核心范围下5/6跨过0.5。该变化属于事后预处理敏感性诊断；只有2种成功蛋白和1个骨架家族，无法据此计算有效特异度或证明新骨架泛化。

#### Learn → 下一轮设计

预先统一蛋白分析范围，并在训练和新数据上使用同一规则。密度按长度归一化仍可能对端部变化敏感。不同RNA和同源骨架记录必须分组，重复WT不增加独立阳性骨架数。评分恢复不能解释为结构重新折叠，也不能用于推断三个C的编辑率。

**仓库处理：**独立 `trm_validation/` 目录删除。本节保留质控发现；当前跨骨架流程中的已有TRM敏感性输入及结果保持不变，用于解释现有模型边界。

### Cycle 5：C388 固定50%标签检验骨架模型能否迁移到活性任务

#### Design

对31种有实验标签的TRM构建，以两次C388编辑率均值≥50%定义达标。检验旧骨架模型直接迁移，以及基于相同低维特征重新训练的可行性。

#### Build

31种蛋白中22达标、9未达标；采用C388配对15 nt RNA结构，统一512 aa分析范围。WT包含于该阶段；无标签P4-R5-VTF排除。比较冻结骨架模型、CP/结构/RNA特征的LR和浅层RF，以及训练内模型选择。采用LOCO及突变位置组合留出。P4+P7与单P4/P7可能共享组成位置，因此后者尚未严格隔离每个突变位置。

#### Test

| 模型/流程 | 留一或迁移AUC | 对应BA | 位置组合AUC | 位置组合BA |
|---|---:|---:|---:|---:|
| 冻结三密度RF直接迁移 | 0.331 | 0.396 | — | — |
| 重训三密度LR | 0.722 | 0.753 | 0.697 | 0.674 |
| 重训CP＋结构LR | 0.778 | 0.606 | 0.798 | 0.707 |
| 训练内选择10候选 | 0.576 | 0.606 | 0.702 | 0.684 |
| RNA4 LR | 0.566 | 0.619 | 0.556 | 0.573 |
| RNA4 RF | 0.439 | 0.374 | 0.500 | 0.452 |
| Structure6 RF | 0.561 | 0.485 | 0.535 | 0.540 |

冻结模型在9个未达标中误报8个。全判达标也有71.0% accuracy，所以不能只报告普通准确率。normalized Rg存在原始关联，但16候选BH q≈0.123，未通过校正。剔除两个“未检出变体记录而记0”的构建后，三密度LR/CP＋结构LR的LOCO AUC降至0.656/0.708，提示低端记录影响结果。
