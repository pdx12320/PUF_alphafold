# Figure source data

These CSVs are generated by [make_figures.py](../scripts/make_figures.py) from the recorded repository results. [source_manifest.json](source_manifest.json) records each source path, source row count and SHA-256 digest. The plotting script does not retrain a model or alter any original result.

| File | Contents |
|---|---|
| `fig1_model1_four_construct_confusion_predictions.csv` | Four jointly excluded RF CP + structure predictions, merged with recorded construct labels |
| `fig1_model1_four_construct_confusion_counts.csv` | Four-construct confusion counts, rows measured and columns predicted |
| `fig2_model1_loco_confusion_predictions.csv` | Twenty-four RF CP + structure LOCO predictions and recorded labels |
| `fig2_model1_loco_confusion_counts.csv` | LOCO confusion counts, rows measured and columns predicted |
| `model2_selected_five_complete.csv` | All 15 selected construct–endpoint records, with fold-specific thresholds, original measurements/differences, matched controls and agreement flags |
| `fig3_model2_five_construct_confusion_counts.csv` | Endpoint-specific confusion counts in long format |
| `fig4_model2_measured_percent.csv` | Five constructs × three measured editing percentages |
| `fig4_model2_matched_delta_pp.csv` | Five constructs × three changes from matched controls, in percentage points |
| `fig5_model3_nontrm_consensus.csv` | All 17 consensus non-TRM candidate substitutions and both model frequencies |

`matched_control_percent` is computed as `experimental_percent − delta_pp`, preserving the original matched contrast. `correct` means `true_class == predicted_class`. Figure values are rounded for display only; CSVs retain numerical precision.

For Model 2, each selected construct is excluded from its own LOCO training fold. Selected thresholds and algorithms may vary by endpoint and fold. For Model 3, `generated_sequences_per_model` is 10,000; `ligandmpnn_f_max` and `proteinmpnn_f_max` are frequencies of the nominated most frequent residue among generated sequences. The nominated amino acid is the same across the two models at every displayed consensus position.
